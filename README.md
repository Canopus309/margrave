# 변경백 (Margrave) — 3a단계 프로토타입

왕국 변경의 전진 기지를 지키는 판타지 공성 방어 로그라이크. 지금은 전투, 병력 성장, 내정(성 안 건물·민가·자원·달 턴)까지 들어 있다.
설계 문서: https://claude.ai/artifact/VFiVfX6VAACp21RJ8oq5Yr

## 실행

**데스크톱 앱 (추천):** `dist\변경백.exe`를 더블클릭한다. 설치 없이 바로 실행되는 단일 파일이다.
저장은 `문서\변경백` 폴더의 `.json` 파일로 남는다 (자동 저장 `margrave_save_v2.json`, 슬롯 `margrave_slot_1~3.json`).
F11 전체 화면, F12 개발자 도구.

```
npm install        # 처음 한 번
npm start          # 개발 중 앱 실행
npm run dist       # dist\변경백.exe 만들기
```

**브라우저:** `index.html`을 바로 열거나 `node serve.js` → http://localhost:5180 (저장은 브라우저 안에만 남는다)

## 1단계에 들어간 것

- 중앙 본성과 4면 성벽. 한 면 = 성벽 4조각 + 성문, 조각마다 체력이 따로 있고 무너진 곳만 뚫린다
- 성문은 약한 요충지: 적 일부가 노리고, 부서지면 적도 지나간다 (멀쩡할 때는 아군만 통과)
- 휠 확대·축소, 가운데 버튼 드래그·WASD·방향키로 화면 이동, H로 성 중앙
- 장수 부대 4개 + 성주 근위대, 우클릭 이동·집중 공격, 성벽 위 한 줄 배치
- 성주 직할 병력을 구역별로 나눠 성벽 위에 배치, 구역이 무너지면 수비대 부대로 전환
- 적 3종(고블린, 늑대 기수, 오크 전사), 3파 습격, 정찰된 습격 방향
- 장수가 쓰러지면 부대 공격력 하락, 성주가 전사하면 전군 사기 하락
- 전투 후 쓰러진 병사의 경상·중상·사망 판정

## 2단계에 들어간 것

- 전투가 끝나면 정비 화면으로 돌아오는 연속 전투. 전투마다 레벨 +1, 5번째마다 대습격. 지면 캠페인 종료
- 장수 경험치(부대 처치·회복·생존)와 레벨(최대 15). 레벨 1당 부대 전체 +2%, Lv.5·10에 통솔 +1
- Lv.5 전직(갈래 2개), Lv.10 승급. 전직 효과는 부대 전체에 적용
- 무기(장수 전용, 4등급). 등급은 장수 공격력, 옵션은 부대 전체에 적용. 이기면 1개 획득
- 부상: 일반 병사는 경상 1전투·중상 2~3전투 결장, 장수는 2~3전투 결장. 병원 수용 20명
- 긴급 동원: 부상 장수(체력 절반, 쓰러지면 전사)와 부상병(체력 70%/40%, 또 쓰러지면 사망 위험 큼)
- 장수가 빠지거나 전사한 부대는 지휘관 없이 출전(공격력 하락)
- 성주 전사 시 후계자가 이음(혈족·자녀는 3단계)
- 브라우저에 진행 저장

## 3a단계에 들어간 것

- 한 턴 = 한 달, 매달 행동력 3. 습격은 가끔(초반 5~8개월마다) 오고, 정찰·감시탑으로 날짜·방향·구성을 미리 안다
- 성 안 14×14칸에 건물 배치 (성벽 안길·십자 큰길·본성 자리는 비움). 건물 10종, 각 3단계
- 건물은 전투 맵에 그대로 나오고 이동을 막는다. 아군은 격자 길찾기로 돌아가고, 적은 흐름장을 따라 본성으로 가며 막히면 건물을 부순다
- 적의 35%는 약탈자: 성 안에 들어오면 가까운 건물·민가부터 부순다. 민가가 부서지면 주민을 잃는다
- 성 밖 들판에 농장·벌목장·광산 (적이 부수지 않음). 계절마다 생산량이 달라짐
- 자원 4종(골드·식량·목재·철), 주민(세금·신병의 원천), 보관 한도. 식량이 바닥나면 탈영과 사기 저하
- 성벽·성문·본성·건물 피해가 다음 전투까지 남고, 목재로 수리한다. 사원이 있으면 본성이 매달 회복
- 행동: 건설·강화, 수리, 모집(병영·주민 필요), 훈련(훈련장), 정찰, 무기 제작(대장간)
- 병원은 건물(단계당 20명), 경상 1개월·중상 3~6개월. 마법사·사제 부대는 마법탑·사원이 있어야 보충
- 시장 거래(식량·목재·철), 시세는 매달 랜덤하게 움직이고 식량은 계절을 탄다. 병사 급여(유지비)

## 3b-1단계에 들어간 것

- 장수 특성 1~2개(좋은 특성 7종, 단점 3종). 부대 능력·통솔·경험치에 영향
- 나이: 해마다 먹고, 50세부터 능력 감소, 60세부터 노환으로 세상을 떠날 수 있음. 45세부터 은퇴(교관 → 훈련 경험치 +)
- 가문: 성주가 20~45세일 때 해마다 25% 확률로 자녀 출생, 16세에 장수가 됨
- 후계: 성주가 전사하거나 늙어 죽으면 혈족(장수가 된 자녀, 어린 자녀) 중에서 고름. 어린 성주는 16세까지 전투 불참. 혈족이 없으면 가문 단절로 끝
- 장수 영입: 주점(떠돌이 장수 고용), 발탁(훈련장 2단계, 직할 병사를 장수로). 본국 파견은 3b-2
- 장수 부대의 시작 자리는 출전 순서대로 십자 큰길 → 성벽 안길

## 3b-2단계에 들어간 것

- 원정: 계절마다 원정지 3곳(고블린 둥지·버려진 광산·상인 호위·고대 유적). 장수 부대 하나를 행동력 2로 보내 1~2개월 뒤 귀환
  - 성공 확률 = 부대 전력 ÷ 난이도. 성공하면 보상(둥지는 다음 습격 규모 -25%), 실패하면 부상자. 원정 간 부대는 성을 못 지킨다
- 랜덤 이벤트 8종(매달 20%): 떠돌이 상인, 난민, 역병, 풍작, 병충해, 도둑, 의용병, 왕실의 부탁. 선택이 필요한 것은 창으로 뜬다
- 본국 관계(0~100, 해임 없음): 습격 승리 +3, 부탁 수락 +10·거절 -5. 지원 요청(관계 -15, 2~4개월 뒤 장수·병사·식량), 계승 축하 선물

## 새 병종과 원거리 적

- 공병(통솔 1당 5명): 전투 중 근처 성벽·성문·건물·본성을 자동 수리, 무너진 곳도 다시 세움. 성에 있으면 수리 목재 -40%. 공방에서 보충
- 포병(통솔 1당 3명): 사거리 330, 6초마다 범위 공격, 가까운(90 안) 적은 못 쏨. 공방에서 보충
- 기병: 빠르고 튼튼, 40px 이상 달린 뒤 첫 타격 3배(돌격). 성벽 위에 못 올라감(성벽을 누르면 바로 안쪽에 섬). 마구간에서 보충
- 새 병종 모두 Lv.5 전직 두 갈래와 Lv.10 승급
- 고블린 궁수(3번째 전투부터): 성벽 밖에서 멈춰 쏜다. 성벽 위 병력과 직할 수비대도 맞지만 명중률 50%
- 오크 투석병(5번째 전투부터): 멀리서 성벽에 큰 피해
- 모든 적이 나온 뒤 60초 동안 적이 하나도 안 죽으면 남은 적은 물러난다 (끝나지 않는 전투 방지)

## C1단계에 들어간 것 (연대기·명성)

- 연대기 사건 8종(2~3년마다 하나, 선택에 따라 효과): 징집령, 대이주, 혹한, 금맥, 순례단, 혼담, 이웃 사절, 민심 동요
- 연대기 창: 성주 계보(대·다스린 때·끝)와 부임·전투·장수·출생·사망·사건 기록
- 끝나면 계보와 명성(버틴 해·승리·정벌 거점·대 수)을 보여주고 명성을 모아 둔다
- 새 캠페인 준비 창에서 명성으로 해금: 영지 특성 4종(광산 지대·비옥한 들판·국경 요새·상업 도시), 시작 보너스 4종(넉넉한 창고·객장·공방·마구간), 포위 단계 1~5(적 +15%씩, 명성 +25%씩)
- 해금 기록은 `margrave_meta`에 따로 저장되어 캠페인이 끝나도 남는다

## C2-1단계에 들어간 것 (거점 정벌)

- 내정 화면의 정벌 카드: 거점 3곳(순서 자유) — 고블린 소굴★(숲)·오크 전쟁 야영지★★(평원)·트롤 늪 요새★★★(늪)
- 정찰(골드 50, 행동력 1)로 보스 특징과 수비 규모를 알아냄
- 출정: 장수 부대 2개 이상 + 성주 친정(선택), 식량 300, 행동력 2. 다음 달 도착해 정벌 전투, 이기든 지든 남은 달 동안 돌아옴. 그동안 남은 병력으로 성을 지킴
- 정벌 전투: 매번 무작위 지도(숲·바위·물), 목책(문 3곳)·망루·적 본진. 본진을 부수면 승리, 언제든 퇴각 가능
  - 진지 구조물은 포병 ×2.5·공병 ×2·마법 ×0.5, 나머지는 ×0.25 피해
  - 아군이 진지에 다가오면 경보가 울려 수비대 전체가 나옴. 보스가 살아 있으면 30초마다 본진에서 증원
  - 90초 동안 아무도 적에게 피해를 못 주면 물러남
- 보스: 고블린 왕(졸개 소환, 체력 35%에서 진지 안쪽으로 도주), 오크 대족장(함성으로 주변 적 공격력 1.5배, 돌진·밀쳐내기), 거인 트롤 족장(재생, 범위 강타). 보스를 쓰러뜨리면 증원이 끊기고 적 공격력 -20%, 전설 무기를 얻음
- 보상: 골드, 명성(거점당 50), 고블린 소굴=습격 규모 -15%, 오크 야영지=매달 철 +20·습격 오크 -30%, 트롤 늪=매달 목재 +30·식량 +20
- 정벌에 성공하면 늦어도 2개월 안에 그 세력의 보복 습격(×1.5). 실패하면 그 거점 수비 +20%

## C2-2단계에 들어간 것 (검은 성채·엔딩)

- 검은 성채★★★★(돌 요새): 거점 3곳을 모두 정벌하면 열림. 목책 대신 돌벽(체력 900), 대군 수비대, 본진 체력 18000
- 고대 드래곤: 날아다녀 벽·지형을 무시, 7초마다 불숨(부채꼴 반지름 170, 맞은 병사는 3초간 화상)
- 함락하면 엔딩 화면: 정벌의 기록, 성주 계보, 지금 마치면 받는 명성(엔딩 +100 포함)
  - 계속 다스리기: 캠페인이 이어지고 습격이 해마다 10%씩 커짐. 끝날 때 엔딩 보너스 포함한 명성을 받음
  - 여기서 이야기를 마치기: '평정'으로 끝나고 명성을 받음

## A단계에 들어간 것 (전투 스킬·소모품)

- 병종마다 스킬 하나 (장수가 살아 있어야 씀, Lv.5 전직 갈래에 따라 강화). 부대를 고르고 Q 또는 부대 카드의 스킬 버튼. 땅을 찍는 스킬은 조준 후 클릭(우클릭·Esc 취소), 일시정지 중에도 가능
  - 보병 방패벽, 궁수 화살비, 마법사 대폭발, 사제 축복, 공병 긴급 보수(전투공병은 정벌전 폭약), 포병 집중 포격, 기병 돌파, 성주 근위대 변경백의 깃발
- 소모품 5종: 치유 물약·화염 항아리·전투 북·끓는 기름(방어전)·응급 목재(방어전)
  - 시장이 있으면 골드로 구입(종류마다 9개까지), 원정 성공 때 40% 확률로 하나
  - 전투 준비 단계에서 3종까지 챙기고, 전투 중 버튼으로 사용. 쓴 만큼 전투가 끝나면 줄어듦

## D단계에 들어간 것 (사운드·연출)

- 소리는 파일 없이 Web Audio로 합성 (`js/audio.js`): 칼·화살·폭발·성벽 붕괴·뿔나팔·함성·불숨·스킬·회복·승리/패배·버튼
- 배경음: 전투는 북 장단, 내정은 잔잔한 화음. 왼쪽 아래 🔊 버튼에서 효과음·배경음 음량과 소리 끄기 (설정은 저장됨)
- 화면 흔들림: 성벽 붕괴, 포격, 구조물 붕괴, 보스 기술, 범위 스킬
- 피해 숫자: 장수·성주·보스·진지 구조물만
- 배너: 전투 시작, 제2·3파 습격, 진지 경보, 보스 격파, 적 본진 함락, 성주 전사
- 전장 흔적: 쓰러진 자리에 90초 동안 옅게 남음
- 계절 날씨(화면 효과만): 겨울 눈(땅도 하얗게), 가을 낙엽, 늪 안개, 검은 성채 재
