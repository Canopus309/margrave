# 변경백 (Margrave) — 1단계 전투 프로토타입

왕국 변경의 전진 기지를 지키는 판타지 공성 방어 로그라이크. 지금은 "부대를 지휘하는 게 재밌나?"를 확인하는 전투 한 판만 들어 있다.
설계 문서: https://claude.ai/artifact/VFiVfX6VAACp21RJ8oq5Yr

## 실행

`index.html`을 브라우저로 바로 열거나, 로컬 서버로 띄운다.

```
node serve.js
```

→ http://localhost:5180

## 구성

| 파일 | 내용 |
| --- | --- |
| `js/data.js` | 병종·적·시작 병력·웨이브 수치 (밸런스는 여기서) |
| `js/battle.js` | 성벽 통과 판정, 경로, 부대·적 AI, 직할 수비대, 승패 |
| `js/render.js` | 캔버스 그리기 |
| `js/input.js` | 선택, 이동·공격 명령, 부대 지정 |
| `js/ui.js` | 사이드바, 결과 화면 |
| `js/main.js` | 메인 루프 |

## 1단계에 들어간 것

- 중앙 본성과 4면 성벽. 한 면 = 성벽 4조각 + 성문, 조각마다 체력이 따로 있고 무너진 곳만 뚫린다
- 성문은 약한 요충지: 적 일부가 노리고, 부서지면 적도 지나간다 (멀쩡할 때는 아군만 통과)
- 휠 확대·축소, 가운데 버튼 드래그·WASD·방향키로 화면 이동, H로 성 중앙
- 장수 부대 4개 + 성주 근위대, 우클릭 이동·집중 공격, 성벽 위 한 줄 배치
- 성주 직할 병력을 구역별로 나눠 성벽 위에 배치, 구역이 무너지면 수비대 부대로 전환
- 적 3종(고블린, 늑대 기수, 오크 전사), 3파 습격, 정찰된 습격 방향
- 장수가 쓰러지면 부대 공격력 하락, 성주가 전사하면 전군 사기 하락
- 전투 후 쓰러진 병사의 경상·중상·사망 판정
